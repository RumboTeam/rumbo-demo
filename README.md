# Rumbo · demo

Versión de prueba de **Rumbo**, un juego sobre la vida y el dinero en un barrio. La demo llega hasta el día 24.

- Se juega en el navegador (mejor en el teléfono, en vertical). No hace falta instalar nada.
- La partida se guarda solo en tu navegador. El juego no tiene cuentas, no pide datos y no se conecta a ningún servidor.
- Las voces de Mario se generaron con IA.

Este repositorio contiene solo la versión compilada de la demo, no el código fuente.
